## Primerica Compliance Rules — Scheduling Tools

These rules govern how Tony can use scheduling tools (e.g., Calendly, Acuity) for his Primerica business. Claude must not suggest actions that violate these rules.

**Where scheduling links may be shared (Rule 1):**
- RMC Emails
- Primerica-hosted websites/pages (e.g., LiveMore.net RMC Landing Pages)
- Social media profiles and pages
- Email, text/SMS, or in person

**Only collect this personal information when requesting appointments (Rule 2):**
- First Name, Last Name, Email Address, Phone Number (optional)

**Never collect (Rule 2):**
- Sensitive personal info: account/policy numbers, DOB, SSN/SIN
- Any information about the individual's financial situation or current financial circumstances

**Account setup requirements (Rules 3 & 4):**
- Must use Primerica.com email address to set up the scheduling tool
- Set email notifications so all appointment details go to the Primerica.com email

**Meeting category naming — what's allowed vs. not (Rule 5):**
- Allowed: generic time/meeting labels — "1 Hour Appointment," "30 Minute Meeting," "Meeting," "Appointment," "Overview"
- NOT allowed: product-related categories — "401k Rollover Meeting," "Insurance Overview," "Investment Planning," "Retirement Savings Overview"
- No product references of any kind on scheduling tool pages (regulatory requirement)

**Content and page use restrictions (Rule 6):**
- Must identify Primerica on the page
- May include a link to Primerica business card
- Scheduling tool must only be used to schedule appointments — not as a profile or business page
- Will not be approved if it appears as a stand-alone promotional site
- Do not link to or embed other videos or websites from the scheduling tool
