## SEO Checklist for Every Blog Post

### On-Page SEO (required for every post)
- [ ] Primary keyword in: H1, first 100 words, at least 2 subheadings, meta description, URL slug
- [ ] Meta title: 50–60 characters with keyword near the front
- [ ] Meta description: 150–160 characters with keyword and compelling CTA
- [ ] Canonical URL set
- [ ] Schema.org BlogPosting markup
- [ ] FAQ Schema for posts with FAQ sections (targets People Also Ask)
- [ ] Open Graph tags (og:title, og:description, og:image, og:url, og:type=article)
- [ ] Image alt text on all images
- [ ] Internal links: minimum 2 to other blog posts + 1 to homepage
- [ ] External link: 1–2 authoritative external links (Google, industry stats)
- [ ] CTA sections: top (after intro), middle (after problem/key section), end
- [ ] Reading time estimate in post hero
- [ ] Published date

### Content Quality (every post)
- [ ] Word count 1,400–2,200 depending on topic complexity
- [ ] Flesch reading score 60+ (clear, conversational language)
- [ ] Real numbers and specific examples (not generic "many businesses")
- [ ] Distinct H2 structure with keyword-rich subheadings
- [ ] FAQ section targeting Google's People Also Ask
- [ ] At least one visual element (stat box, pricing table, trade breakdown, step list)

### Technical (at publication)
- [ ] HTML file in /blog/[slug]/index.html (clean URLs)
- [ ] File added to /blog/index.html blog listing page
- [ ] Sitemap updated (sitemap.xml)
- [ ] Committed and pushed to GitHub (adecarlo248/1APP)
- [ ] Mirrored to /home/maximus/.openclaw/workspace/use1app.com/blog/
