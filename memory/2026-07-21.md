## 1app GHL Snapshot Library — MASSIVE BUILD DAY

Today was the biggest single session in 1app history. Tony and I built the most comprehensive trades snapshot library ever created for GoHighLevel.

### What We Built

**Architecture Decision:**
- One template sub-account per trade (not 3 per tier)
- From one sub-account, create 3 tier-specific snapshots by selecting different assets
- 5 trades = 5 sub-accounts = 15 snapshots total (Tier 1/2/3 per trade)
- Snapshots are UI-only in GHL — API cannot create them. Tony clicks "Create Snapshot" at the end.

**GHL MCP Config:**
- Added all trade template sub-accounts to `~/.mcporter/mcporter.json`
- Pattern: `gohighlevel-[trade]-template` as the server key
- Each requires location ID + API token (pit-xxxx format)

**Build Pattern (every trade):**
- Phase 1: Custom Fields (contact-level, 17-22 fields per trade)
- Phase 2: Pipelines (2-6 pipelines, 7-20 stages each)
- Phase 3: Calendars (3-4 per trade)
- Phase 4: Tags (18-33 per trade)
- Phase 5: Workflows — CANNOT be created via GHL API, fully documented in build logs with exact SMS/email copy
- GHL API note: Use `SINGLE_OPTIONS` not `DROPDOWN`, `RADIO` not `CHECKBOX`, `MONETORY` (not monetary)
- Calendar hours must be set manually in GHL UI (API rejects openHours format)
