## Gate 1 — Quote and Trial

- [ ] Custom quote and trial scope accepted in writing
- [ ] Trial path marked: Starter Trial Eligible / Paid Implementation Required
- [ ] One approved starter automation named when a free trial is offered
- [ ] Starter trial uses an approved template
- [ ] Starter trial targets 1–3 business days after Ready-to-Build
- [ ] Tony hands-on setup estimate is four hours or less
- [ ] Current capacity allows the launch: maximum four live trials and two new launches/week unless Tony approved an exception
- [ ] One revision round and paid change-control rule disclosed
- [ ] Advanced/custom work separated into a paid setup project
- [ ] Every automation is listed with scope and exclusions
- [ ] Post-trial monthly price, setup fee, tax, and billing cadence verified
- [ ] 14-day trial start trigger and end date defined
- [ ] Trial start recorded only after the starter automation is live, tested, and usable
- [ ] No credit card required to start trial confirmed
- [ ] Trial success measures recorded
- [ ] Associate attribution recorded
- [ ] Sales-to-fulfillment handoff accepted
